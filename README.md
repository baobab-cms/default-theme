# Baobab CMS — thème par défaut

Le thème par défaut de Baobab CMS : le rendu public livré avec le squelette. Il sert de point de départ et de référence pour construire un thème, et il est remplaçable par n'importe quel autre thème installé.

Il est installé automatiquement avec le squelette :

```bash
composer create-project baobab/baobab monsite
```
